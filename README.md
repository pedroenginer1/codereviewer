Uma ferramenta Full-Stack desenvolvida para realizar análises automáticas de código utilizando Inteligência Artificial. O sistema avalia boas práticas de programação (Clean Code), aponta bugs de lógica e identifica vulnerabilidades de segurança em segundos.

## 🛠️ Tecnologias Utilizadas

* **Back-end:** Java 17 + Spring Boot 3 (Spring AI para integração)
* **Front-end:** HTML5 + Tailwind CSS + JavaScript (Fetch API)
* **Core IA:** Google Gemini 2.5 Flash API
* **Segurança:** Isolamento de credenciais via Variáveis de Ambiente (`${GEMINI_API_KEY}`)
